# CODSOFT Data Science Internship 🚀

This repository contains all the tasks completed as part of the **Data Science Internship at CODSOFT**.  
Each task is organized in a separate folder and demonstrates practical implementation of Machine Learning concepts using Python.

---

## 📁 Tasks Included

### 🔹 Task 1: Titanic Survival Prediction
- Predict whether a passenger survived the Titanic disaster using ML classification techniques.
- Concepts: Data Cleaning, EDA, Feature Engineering, Model Building

### 🔹 Task 2: Movie Rating Prediction
- Predict movie ratings based on features like genre, director and cast.
- Concepts: Regression, Data Preprocessing, Feature Encoding

### 🔹 Task 3: Iris Flower Classification
- Classify iris flowers into Setosa, Versicolor, and Virginica.
- Concepts: Classification, Visualization, Model Evaluation

### 🔹 Task 4: Sales Prediction (Optional)
- Forecast product sales using advertising data.

### 🔹 Task 5: Credit Card Fraud Detection (Optional)
- Detect fraudulent transactions using classification models.
