# Iris Flower Classification – CODSOFT Data Science Internship

This project is part of the **CODSOFT Data Science Internship** program.  
The objective of this task is to build a machine learning model that can accurately classify Iris flowers into their respective species based on sepal and petal measurements.

---

## Objective

To develop a classification model that predicts the species of an Iris flower using:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Target classes:
- Setosa
- Versicolor
- Virginica

---

## Dataset

The Iris dataset is a well-known and widely used dataset in machine learning for classification tasks.  
It is clean, balanced, and ideal for learning supervised classification techniques.

Source: Built-in dataset from `sklearn.datasets`

---

## Steps Followed

1. **Data Loading** – Loaded Iris dataset using `load_iris()` from scikit-learn.
2. **Data Exploration (EDA)** – Analyzed dataset structure, statistics, and class distribution.
3. **Feature & Target Separation** – Defined independent variables (X) and dependent variable (y).
4. **Train-Test Split** – Split data into 80% training and 20% testing sets.
5. **Model Training** – Trained a Logistic Regression classifier.
6. **Prediction** – Predicted species on test data.
7. **Evaluation** – Evaluated model using:
   - Accuracy Score
   - Confusion Matrix
   - Classification Report (Precision, Recall, F1-score)

---

## Results

The model achieved **high accuracy** in classifying Iris flowers and performed well across all three species.  
This demonstrates the effectiveness of Logistic Regression for multi-class classification problems.
