# CODSOFT
Data Science Internship Tasks 1 completed during CODSOFT Internship. # Titanic Survival Prediction

This project is part of the CODSOFT Data Science Internship.

## Objective
To predict whether a passenger survived the Titanic disaster based on features such as age, gender, class, and fare.

## Steps Followed
- Data Loading
- Exploratory Data Analysis (EDA)
- Data Cleaning
- Feature Encoding
- Train-Test Split
- Model Training (Logistic Regression)
- Model Evaluation

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

## Result
The model achieved good accuracy in predicting passenger survival.
